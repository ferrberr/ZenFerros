# ADR-007: Backend C de bootstrap para completar el primer hito

**Fecha**: 2026-11-11
**Estado**: ACEPTADA
**Responsable**: 00 Orquestador
**Dependencias**: TASK-210, ADR-001

## Problema y evidencia local

La CLI heredada anunciaba comandos que solo imprimían un aviso. `src/lib.rs` no exponía parser/AST. No había semántica ni codegen. ADR-001 indicaba LLVM/inkwell; TASK-201 cambió a Cranelift sin actualizar arquitectura. Cargo mezclaba Cranelift 0.112 con cranelift-faerie 0.66; no existía integración de esos crates en un backend real. `cc` está disponible; LLVM/Clang no aparecen en PATH en esta sesión.

## Decisión

Para Hito 1, implementar frontend Zen pequeño con validación propia, emitir C11 y compilar/enlazar usando `cc`. Retirar dependencias de backend y generación de parser que el compilador no usa. Conservar borradores anteriores de AST/gramática sin compilarlos. El backend actual se anuncia con veracidad en CLI, README y arquitectura. Esta decisión sustituye la elección de implementación de backend de ADR-001 para el MVP ejecutable; los informes antiguos permanecen como historial.

## Alternativas

- LLVM/inkwell: buen camino de optimización a futuro, pero necesita toolchain que no está presente y trabajo de integración adicional.
- Cranelift coherente y cranelift-object: viable, pendiente evaluación con dependencias de la misma versión; el esqueleto heredado no lo implementaba.
- C11 + cc: usa herramientas ya disponibles, genera binarios reales y permite concentrarse en semántica y pruebas del lenguaje para cerrar Hito 1.

## Consecuencias y revisión

Sin afirmaciones de velocidad frente a otros lenguajes. La compilación depende del compilador C del host; el frontend controla tipos, orden de evaluación, scopes y semántica de enteros. Las pruebas verifican normal/optimizado. Antes del Hito 2 se evaluará emisión de objetos freestanding mediante este backend o migración a Cranelift/LLVM; no se anuncia soporte bare-metal por producir ELF hosted.

## Aceptación

Hello y factorial compilados a ELF y ejecutados, pruebas negativas de tipos/nombres/léxico, revisión cruzada y métricas registradas en TASK-210/TASK-211.
